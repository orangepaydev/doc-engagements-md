# Templates

Two templates: one living tracker file per project plus an occasional progress snapshot. See
[`../README.md`](../README.md) for the reasoning.

| Template | Use |
| --- | --- |
| [`project-tracker-template.md`](project-tracker-template.md) | One file per project (saved as the project folder's `README.md`), updated in place as it moves from idea through validation, build, delivery, and outcome. |
| [`progress-report-template.md`](progress-report-template.md) | Point-in-time progress snapshot for a project that's been running a while (e.g. monthly, or on request) — status, what moved, hours/cost, blockers, next steps. Saved as `progress-report-YYYY-MM-DD.md` in the project folder. |

# Prompt to create an initial NextJS project

Use the following prompt to create an initial NextJS project
```text
As a FrontEnd Developer, who is proficient in Node, TypeScript, React, and TailwindCSS, shadcn UI, pnpm and nextjs

create an initial project in the current folder with TypeScript and TailwindCSS, shadcn UI, pnpm and nextjs.

The project should have a basic layout with a header and footer.

The header should have a logo and a navigation menu.

The footer should have a copyright notice and a link to the GitHub repository.

Also include the linter and a commit hook that lints the project before each commit.
```
